BC ESTÉTICA AVANÇADA — PADRÃO DE VÍDEOS PARA O SITE

Pasta oficial: assets/videos/

Formato recomendado para máxima compatibilidade web:
- Contêiner: MP4
- Vídeo: H.264 / AVC
- Perfil: High ou Main
- Pixel format: yuv420p
- Áudio: AAC-LC, 128 kbps, 44.1 kHz ou 48 kHz
- FPS: 30 fps recomendado
- Resolução vertical: 1080x1920 (9:16)
- Resolução horizontal, quando necessário: 1920x1080 (16:9)
- Fast Start / Web Optimized: ativado (moov atom no início)
- Evitar HEVC/H.265, ProRes, MOV pesado e codecs proprietários para uso direto no site.

Nomes padronizados sugeridos:
- bc-estetica-video-01.mp4
- bc-estetica-video-02.mp4
- bc-estetica-video-03.mp4
- bc-estetica-video-04.mp4

Regras de nome:
- somente letras minúsculas, números e hífens
- sem espaços
- sem acentos
- extensão .mp4

Depois do upload, o caminho público será, por exemplo:
assets/videos/bc-estetica-video-01.mp4
